# Implementation Plan: Real-Time Multiplayer Shared Cart

**Branch**: `019-realtime-shared-cart` | **Date**: 2026-06-04 | **Spec**: `specs/019-realtime-shared-cart/spec.md`

## Summary

Add real-time WebSocket synchronization to the existing shared cart (CartSession/CartItem). REST endpoints (already implemented for add/remove) remain the write path. A new `CartConsumer` broadcasts `cart_updated` events to all session participants whenever CartItem is created, updated, or deleted. A service-layer broadcast helper wrapped in `transaction.on_commit()` triggers the broadcast — this guarantees the DB write commits *before* the WebSocket message is sent, preventing clients from reading stale state on re-fetch. The frontend re-fetches cart state on event receipt and on WebSocket reconnect.

## Technical Context

**Language/Version**: Python 3.12, Django 5.0+
**Primary Dependencies**: channels, channels_redis, djangorestframework, drf-spectacular
**Storage**: PostgreSQL (CartSession, CartItem), Redis (Channel Layer)
**Testing**: pytest, pytest-django, channels test helpers
**Target Platform**: Linux server (Docker)
**Project Type**: Web service (Django REST + Channels)
**Performance Goals**: Broadcast to all session participants within 100ms of DB write.
**Constraints**: WebSocket is read-only; mutation goes through REST with `select_for_update`.
**Scale/Scope**: Enterprise restaurant platform; one cart session per reservation.

## Phases

### Phase 1: WebSocket Consumer & Broadcast Layer

1. Create `apps/orders/consumers.py` with `CartConsumer` (AsyncWebsocketConsumer, read-only)
2. Create `apps/orders/routing.py` with `ws/cart/<session_id>/` route
3. Create `apps/orders/broadcast.py` with `cart_group_send(session_id, event_type)` helper — uses `async_to_sync(channel_layer.group_send)` so it can be called from sync service code
4. Update `core/routing.py` to include orders websocket patterns
5. Update cart mutation services (`add_item_to_cart`, `remove_item_from_cart`, quantity update) to call `transaction.on_commit(lambda: cart_group_send(...))` after each write
